Q&A CRUD App — Spec









Sep 22, 2026 · @kevin
Overview
A very simple Q&A website where users sign up, post questions, and answer each other's questions. It is a school learning project about database design and CRUD, so simple and readable code matters more than features.
• Built in Replit using the Replit Agent
• Uses an existing MySQL database hosted outside Replit (managed in phpMyAdmin)
• Database login details are stored in Replit Secrets, never in the code

Database connection and Replit Secrets
All credentials come from Replit Secrets through process.env. Nothing sensitive is written in the code or committed to GitHub.

• Create one shared connection pool in a file like db.js and reuse it everywhere
• If a secret is missing, the app should print a clear error on startup
• DB_HOST is not 127.0.0.1. phpMyAdmin shows 127.0.0.1 because it runs on the same server as the database; Replit needs the host's public address
• The database host must allow remote MySQL connections. Turn this on in the hosting panel (often called "Remote MySQL") before testing

Rules and security basics
These are required even though it is a school project.
• Prepared statements only: every query uses ? placeholders. Never build SQL by joining strings with user input
• Hashed passwords: bcrypt on sign-up, bcrypt.compare on login
• Ownership check on the server: before edit or delete, confirm the post's uid_user matches the logged-in user. Hiding buttons is not enough
• Escape output: use EJS <%= %> (not <%- %>) for anything a user typed
• Validation: no empty fields; title max 150 characters, username max 25
• Errors: show a simple friendly message, never raw database errors
• Code style: small files, clear names, short comments explaining each query so it is easy to learn from
Out of scope
Keep the app simple. Do not add: voting, tags, search, user profiles, password reset, email sending, admin panel, image uploads, or a JavaScript front-end framework.
Done checklist
The app is finished when all of these work:
[ ] App starts on Replit and connects to the external database using Secrets
[ ] New user can sign up; the password shows as a hash in phpMyAdmin
[ ] Duplicate username or email is rejected with a message
[ ] User can log in and log out
[ ] Logged-in user can ask, edit, and delete their own question
[ ] Logged-in user can answer, edit, and delete their own answer
[ ] A user cannot edit or delete someone else's post, even by typing the URL
[ ] Deleting a question also removes its answers
[ ] Logged-out visitors can read but not post
[ ] No credentials appear anywhere in the code
